# Architecture Decisions

This index maps each ADR to a one-line summary so agents can find relevant decisions without
opening every file. Keep it in sync whenever an ADR is added or its status changes.

| ADR | Status | Summary |
| --- | --- | --- |
| [2026-08-25 ADR: author a declined judgement as its own guidance status](<2026-08-25 ADR - author a declined judgement as its own guidance status.md>) | Accepted | `pregnancy-food-safety` gains a fifth list-owned status, `Not enough evidence` (amber, `maybe` band), so a source that declines to judge is not rendered as setting conditions; adds no tone, band, or code, and accepts that the outcome filter cannot separate the two `maybe` statuses. Governs `src/data/guidanceLists.ts` and `src/data/teaAssessments.ts`. |
| [2026-08-13 ADR: derive a display-only combined outcome for collapsed-row summaries](<2026-08-13 ADR - derive a display-only combined outcome for collapsed-row summaries.md>) | Accepted | A render-time fold combines only the generic `outcomeBand` across active guidance lists, treating not-assessed as a caution, solely to summarise a collapsed row; nothing is authored or persisted and per-list statuses stay unmerged wherever guidance is shown. Extends the generic-outcome-filters ADR and governs `src/domain/` and the catalogue surface. |
| [2026-08-10 ADR: model preparation as a catalogue dimension](<2026-08-10 ADR - model preparation as a catalogue dimension.md>) | Accepted | Preparation becomes a global vocabulary that crosses the category tree, with foods declaring their states, derived category groupings, and assessments keyed by `(subject, preparation, list, source)`; retires `fish-mercury-guidance` and governs `src/domain/`, `src/data/preparations.ts`, and the catalogue and food-detail surfaces. |
| [2026-08-08 ADR: model guidance sources as attributed peers within a guidance list](<2026-08-08 ADR - model guidance sources as attributed peers within a guidance list.md>) | Accepted | A guidance list may draw on several attributed sources, keying assessments by `(subject, list, source)` and resolving one labelled layer set with the most cautious status; amends the independent-guidance-lists ADR and governs `src/domain/`, `src/data/sources.ts`, and the guidance components. |
| [2026-08-07 ADR: accumulate inherited guidance through additive assessments](<2026-08-07 ADR - accumulate inherited guidance through additive assessments.md>) | Accepted | An assessment may declare `relation: 'adds-to'` so a specific rule layers onto inherited group guidance instead of replacing it; amends the total-override rule and governs `src/domain/assessment.ts` and `src/components/GuidanceSection.tsx`. |
| [2026-08-07 ADR: resolve unassessed guidance from a single not-assessed state](<2026-08-07 ADR - resolve unassessed guidance from a single not-assessed state.md>) | Accepted | Guidance lists drop their coverage declaration and the `outside-coverage` state; any subject with no resolved rule reads `Not assessed`, governing `src/domain/`, `src/data/guidanceLists.ts`, and the catalogue UI. |
| [2026-08-07 ADR: enforce WCAG 2.2 AA with axe-core in Playwright](<2026-08-07 ADR - enforce WCAG 2.2 AA with axe-core in Playwright.md>) | Accepted | Dedicated `@axe-core/playwright` scans in `e2e/` fail the pre-commit gate on any WCAG 2.2 AA violation, with no allowlist or baseline. |
| [2026-08-06 ADR: vary source-citation requirements by guidance list](<2026-08-06 ADR - vary source-citation requirements by guidance list.md>) | Accepted | Each guidance list declares whether citations are required or optional; pregnancy stays fully cited while a list may instead declare its evidentiary basis. |
| [2026-08-06 ADR: assess categories as first-class subjects with inherited guidance](<2026-08-06 ADR - assess categories as first-class subjects with inherited guidance.md>) | Accepted | An assessment's subject is a food or a category, foods inherit the nearest assessed ancestor's cited guidance, and an assessed category is a searchable, routable guide entry; its total-override rule is amended by the 2026-08-07 additive assessments ADR. |
| [2026-08-06 ADR: show scoped guidance with generic outcome filters](<2026-08-06 ADR - show scoped guidance with generic outcome filters.md>) | Accepted | Catalogue filtering defaults to pregnancy scope and uses generic outcome bands across selected guidance scopes while preserving list-owned assessments; its distinct-fallback-band decision is superseded by the 2026-08-07 single not-assessed state ADR. |
| [2026-08-05 ADR: remove temporal freshness metadata from guidance content](<2026-08-05 ADR - remove temporal freshness metadata from guidance content.md>) | Accepted | Guidance lists retain cited, precisely located sources but no longer carry temporal freshness metadata or overdue validation; its explicit-coverage retention is amended by the 2026-08-07 single not-assessed state ADR. |
| [2026-08-05 ADR: adopt AI-assisted local draft curation for official sources](<2026-08-05 ADR - adopt AI-assisted local draft curation for official sources.md>) | Accepted | A repository skill may create a source-cited local draft from a maintainer-provided official source, but human review remains mandatory before publication. |
| [2026-08-05 ADR: adopt Playwright end-to-end testing and Husky pre-commit validation](<2026-08-05 ADR - adopt Playwright end-to-end testing and Husky pre-commit validation.md>) | Proposed | Playwright Chromium browser tests and a Husky pre-commit hook validate implemented user-facing flows alongside Vitest coverage. |
| [2026-08-05 ADR: enforce complete coverage for application source](<2026-08-05 ADR - enforce complete coverage for application source.md>) | Accepted | Vitest V8 coverage enforces 100% global statements, branches, functions, and lines for application source under `src/`. |
| [2026-08-04 ADR: link assessments to canonical reason foods](<2026-08-04 ADR - link assessments to canonical reason foods.md>) | Accepted | Assessments can cite a typed reason link to a canonical food such as Gelatin without inferring suitability from that food. |
| [2026-08-04 ADR: use independent guidance lists for food assessments](<2026-08-04 ADR - use independent guidance lists for food assessments.md>) | Accepted | Food suitability is an assessment against a list-specific status vocabulary, allowing pregnancy and vegetarian guidance to share one catalogue. |
| [2026-08-04 ADR: store reviewed guide content as version-controlled static data](<2026-08-04 ADR - store reviewed guide content as version-controlled static data.md>) | Accepted | Reviewed food, condition, and citation records live in typed static data validated during development and CI. |
| [2026-08-04 ADR: model food groups as an unbounded category tree](<2026-08-04 ADR - model food groups as an unbounded category tree.md>) | Accepted | A validated parent-reference category tree supports arbitrary group depth and keeps food records separate from categories. |
| [2026-08-04 ADR: use a static TypeScript React SPA](<2026-08-04 ADR - use a static TypeScript React SPA.md>) | Accepted | React, TypeScript, Vite, and React Router provide a client-only, statically hosted application; amended 2026-08-07 to uplift the version baseline to TypeScript 6, Vite 8, and React Router 8. |
